# raktdrishti-anemia-screener
RaktDrishti — A non-invasive anemia screening app that uses smartphone camera analysis of the eye, nails, and skin (with a colour-calibration card) to estimate hemoglobin risk without a blood draw. Built for Omnikon National Hackathon 2026 to enable fast, low-cost screening in resource-constrained settings. 🩸👁️
